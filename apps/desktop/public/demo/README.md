# 自制示例资源

`three-scenes.mp4`：工程原创合成短片，1280×720、24 fps、12 秒、H.264、无音轨。

- 0–4 秒：QUESTION 与一个方块。
- 4–8 秒：PROCESS 与三个框。
- 8–12 秒：RESULT 与圆环。

由 `scripts/generate-demo.sh` 使用 Pillow 与本机已有 FFmpeg 生成；没有抓取、下载任何平台视频。学习笔记与此画面对应。仅用于 UI 演示，不构成模型识别或效果验证。工程作者允许在本工程及后续版本中使用和修改这些原创几何演示内容（CC0-1.0）。生成器工具仅用于开发资源，应用运行不依赖 Python / FFmpeg。
