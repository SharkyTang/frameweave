## 实际交付

- Tauri 2 + React / TypeScript / Vite 桌面 package；生产静态资源内置，稳定标识 `com.sharkytang.frameweave.workbench`。
- `deliverables/D2/FrameWeave.app` 与 ZIP；应用可执行文件为 arm64 Mach-O。构建、签名验证及 SHA-256 见同目录 `BUILD_MANIFEST.json`。
- 最终 FrameWeave.app 约 7 MiB，ZIP 约 2.3 MiB，实际大小与哈希见最终清单。新品牌包签名验证、无服务器独立启动、深层页与窗口恢复通过；人工 Finder 双击是更名前 D2 的验证，本次没有重复人工操作。
- 颜色/字体/间距/圆角/边框 token，共享 Button、IconButton、Badge、Card、Tabs、Field、Modal/Drawer、Toast、EmptyState。
- 八个页面及深层 hash 路由；左右导航、空态、全局命令面板。
- 原生/演示/未连接适配器和首批领域类型，页面不直接访问文件、SQL、服务地址或 invoke。
- 默认个人空空间，与独立内存演示 Repository 隔离。固定数据位于 fixtures，不散落业务 JSX；静态示例拆解明确是人工编写。
- 12 秒原创 H.264 几何示例，来源/许可/生成器在 `public/demo/README.md`；不使用私人视频或平台下载。
