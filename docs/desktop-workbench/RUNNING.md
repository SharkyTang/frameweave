# D2 应用运行说明

日期：2026-10-14。当前为个人自用桌面预览，范围 D0 → D1 → D2；不是 D7 最终版。

## 直接启动应用

最终应用交付在当前工程的 `deliverables/D2/FrameWeave.app`，并提供同目录 ZIP。

1. 解锁 Mac，使用 Finder 打开工程的 `deliverables/D2`。
2. 双击 `FrameWeave.app`。也可以复制到自己的“应用程序”目录后启动。
3. 首次进入个人空空间；点击“查看示例空间”或左上空间切换，体验完整界面。
4. 查看素材库 → 打开自制示例 → 播放并添加笔记 → 从参考新建示例项目 → 编辑脚本、分镜与清单 → 引用方法 → 手动复盘。

应用内置资源；运行本产品不需要启动 `ui:dev`，也不需要打开浏览器或终端。不要求插件、Python、AI、模型或网络。**更名后的 FrameWeave.app 已在 1420 测试服务器停止时，由原生工具打开并验证冷启动、菜单与深层页面恢复。**此前 D2 的用户 Finder 双击验证通过；本次更名后未再次要求用户双击。

构建工具生成了本机 ad hoc 签名，不是 Apple Developer ID 签名，没有公证，不声称适合公开分发。不要关闭全局 Gatekeeper。如本机提示安全限制，先记录提示并使用 macOS 正常的用户确认流程。

原生层用平台 API 取得专用 AppData；本机设置页实际返回 `/Users/shaoqitang/Library/Application Support/com.sharkytang.frameweave.workbench/`。更名时迁移了仅含 shell.json 的旧目录，保留窗口/页面偏好；个人业务数据库和媒体库尚未建立。没有把业务数据放进 localStorage。

| 快捷键 | 行为 |

| Cmd+N | 新建项目；个人态显示阶段说明，演示态创建空白项目 |
| Cmd+O | 显示 D3 本地导入说明 |

| Cmd+Q | 退出；有示例编辑时提示 |

## 开发与重建

从本工程运行：

```sh
cd apps/desktop
npm ci
npm run desktop:dev
```

```sh
npm run typecheck
npm test
npm run native:test
npm run desktop:build
```

框架构建路径：`apps/desktop/src-tauri/target/release/bundle/macos/FrameWeave.app`。交付副本位于 `deliverables/D2/`。要更新交付副本，在最终构建成功后复制 `.app`，不要覆盖正在运行的副本。

浏览器组件测试使用本机 Chrome，不下载浏览器：

```sh
npm run ui:dev
```

另一个终端：

```sh
npm run test:ui
```

测试读取 `127.0.0.1:1420`。此服务器是测试工具，不是生产运行依赖。测试 JSON 在 `apps/desktop/test-results/ui-results.json`。

不需要重新生成演示资源。若要修改自制示例，开发环境需要 Pillow 与 FFmpeg，执行 `scripts/generate-demo.sh`，可用 `WORKBENCH_PYTHON` 指定 Python；这些工具不会进入应用运行依赖。
