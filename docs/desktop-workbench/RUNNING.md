# D2 应用运行说明

日期：2026-10-14。当前为个人自用桌面预览，范围 D0 → D1 → D2；不是 D7 最终版。

## 直接启动应用

最终应用交付在当前工程的 `deliverables/D2/逆向轻抖.app`，并提供同目录 ZIP。

1. 解锁 Mac，使用 Finder 打开工程的 `deliverables/D2`。
2. 双击 `逆向轻抖.app`。也可以复制到自己的“应用程序”目录后启动。
3. 首次进入个人空空间；点击“查看示例空间”或左上空间切换，体验完整界面。
4. 查看素材库 → 打开自制示例 → 播放并添加笔记 → 从参考新建示例项目 → 编辑脚本、分镜与清单 → 引用方法 → 手动复盘。

应用内置资源；运行本产品不需要启动 `ui:dev`，也不需要打开浏览器或终端。不要求插件、Python、AI、模型或网络。**目前这是生产构建与静态资源检查确认的架构；停止服务器后的 Finder 实际启动仍待解锁后验证。**

构建工具生成了本机 ad hoc 签名，不是 Apple Developer ID 签名，没有公证，不声称适合公开分发。不要关闭全局 Gatekeeper。如本机提示安全限制，先记录提示并使用 macOS 正常的用户确认流程。

## 当前可用范围

- 8 页与导航：工作台、灵感素材库、视频拆解、创作导师、创作方法库、我的作品、爆款雷达、设置。
- 个人空间默认没有示例记录；AI / 下载入口说明未接入，雷达显示规划中。
- 演示搜索、筛选、收藏、网格/列表、详情、归档/恢复。
- 内置 12 秒 H.264 自制示例；时间标记、笔记、手动示例拆解。
- 示例如参考 → 空白原创项目；简报、分段脚本、分镜增删/上下移动、拍摄清单、剪辑说明。
- 示例方法卡编辑/引用、项目阶段、手动复盘；本次会话中的更新可见。
- 桌面壳代码实现原生命令、系统菜单、窗口恢复、关闭隐藏、Dock 激活与单实例。以上原生运行行为待 Mac 解锁后实测。

**演示编辑不写磁盘，不写个人资料。**退出后恢复初始示例。关闭窗口设计为隐藏，保留进程；Cmd+Q 退出，有演示修改时设计为明确询问。

不提供真实个人导入、业务 SQLite、真实导出、备份恢复、SRT/TXT 导入、AI 或抓榜单。入口显示对应阶段说明，不会报告假成功。

## 数据与快捷键

原生层用平台 API 取得专用 AppData；macOS 预期为 `~/Library/Application Support/com.sharkytang.qingdou.workbench/`，以设置页真实返回值为准。D1 仅存窗口/页面的 `shell.json`；个人业务数据库和媒体库尚未建立。没有把业务数据放进 localStorage。

| 快捷键 | 行为 |
|---|---|
| Cmd+N | 新建项目；个人态显示阶段说明，演示态创建空白项目 |
| Cmd+O | 显示 D3 本地导入说明 |
| Cmd+S | 显示会话编辑与未落盘说明 |
| Cmd+, | 设置 |
| Cmd+K | 搜索与命令 |
| Esc | 关闭弹窗并恢复焦点 |
| Cmd+W | 关闭/隐藏窗口；不退出 |
| Cmd+Q | 退出；有示例编辑时提示 |

原生菜单快捷键与中文输入法尚未实机验证；浏览器组件焦点/Esc/中文文本测试已通过。

## 开发与重建

从本工程运行：

```sh
cd apps/desktop
npm ci
npm run desktop:dev
```

```sh
npm run typecheck
npm test
npm run native:test
npm run desktop:build
```

框架构建路径：`apps/desktop/src-tauri/target/release/bundle/macos/逆向轻抖.app`。交付副本位于 `deliverables/D2/`。要更新交付副本，在最终构建成功后复制 `.app`，不要覆盖正在运行的副本。

浏览器组件测试使用本机 Chrome，不下载浏览器：

```sh
npm run ui:dev
```

另一个终端：

```sh
npm run test:ui
```

测试读取 `127.0.0.1:1420`。此服务器是测试工具，不是生产运行依赖。测试 JSON 在 `apps/desktop/test-results/ui-results.json`。

不需要重新生成演示资源。若要修改自制示例，开发环境需要 Pillow 与 FFmpeg，执行 `scripts/generate-demo.sh`，可用 `WORKBENCH_PYTHON` 指定 Python；这些工具不会进入应用运行依赖。
