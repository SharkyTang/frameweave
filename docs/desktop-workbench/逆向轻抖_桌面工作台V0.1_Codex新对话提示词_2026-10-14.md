
**第一次复制提示词 A。它要求实际完成 D0 → D1 → D2，交付桌面应用与全部页面后停止。后续使用 B，每次仅做一个阶段；C 用于修复验收失败；D 用于最终桌面验收。**

这次不要再使用 2026-10-13 旧提示词 A：旧提示词先跑模型验证，与当前“先做桌面工作台”要求冲突。

```text
你现在接手我的「逆向轻抖 / AI 视频创作桌面工作台」V0.1 开发。

先阅读当前工作区适用的 AGENTS.md、README，并完整阅读我提供的：

【已经确定，不用再次询问】
1. 我要的是可以从 Finder 启动的 Mac 桌面应用，有自己的窗口、本地文件能力和本地数据。不是浏览器网站、PWA、扩展弹窗，也不是先做网页等以后再套壳。
2. 产品目标是帮助我成为优秀视频创作者：参考视频 → 学习与拆解 → 原创脚本/分镜/拍摄清单 → 方法库 → 自己作品复盘。
3. 当前先做工作台的界面和框架。视频/文案下载插件由我先独立完善，以后再讨论接入；本轮不开发、修改或重构插件、ASR、字幕纠错、Python 推理服务。

只执行 D0 → D1 → D2：

D1：实现真正的桌面运行骨架、原生能力边界、菜单/窗口生命周期，并构建初始 .app。
D2：完成工作台、素材库、视频拆解、创作导师、方法库、我的作品、爆款雷达占位和设置这 8 个页面，以及共享组件、导航、示例数据和状态。

【技术与工程约束】
- 优先复用当前已存在的成熟桌面工程。没有时默认 Tauri 2 + React + TypeScript + Vite；后续本地层用 Rust + SQLite。
- 已有成熟 Electron/Tauri 不要为技术偏好强迁移。没有桌面模块时可以在当前仓库新建独立 desktop package，但不要重建整个仓库或强制改 monorepo。
- 沿用已有包管理器和锁文件；插件目录、Python 环境和它们的依赖属于保护区。
- 不执行破坏性 reset/clean、删库、强推、发布或覆盖我的未提交文件。需要新权限、系统级安装或高风险操作时遵循审批。
- 生产 .app 必须加载打包内置资源，不能依赖 Vite、localhost 网页服务器、Chrome、Python 或网络。
- React 组件不直接写 SQL、HTTP 地址、文件系统路径或散落 invoke；建立清楚的领域类型、端口与桌面/演示/未连接适配器。
- 桌面权限最小化，不为播放视频开放整个主目录，不暴露任意 shell/SQL/文件读取接口。
- 不在本阶段搭微服务、向量库、通用插件市场、模型管理平台。

【视觉和交互】
- 以提供的浅色 macOS 风格概念图作为方向：中文、柔和紫蓝、清楚左导航、克制卡片、内容和创作任务优先。
- 不把它的示例数字、视频标题、AI 结论或乱码当作真实内容照搬；不需要重做三套概念图让我重新选。
- 首页突出继续创作、最近参考素材、导入与新建项目，不做下载后台。
- 全部 8 页能打开，按钮有实际动作或清晰未接入说明。不能点完只弹“成功”却什么都没做。
- 个人工作区默认空状态；示例空间与个人空间隔离，清楚标识“演示”。本阶段尚未持久化的示例编辑要明说。

- 窗口可缩放，标题栏和系统控件不遮挡内容；支持键盘、中文输入法、焦点、正常菜单和退出。

【测试与交付】

3. 检查 1024、1280、1440、1728 宽度附近的布局，并在真实桌面窗口检查主要页面。
4. 输出修改文件清单、运行命令、应用产物实际路径、测试结果、真实/演示/未实现范围。
5. 更新 docs/desktop-workbench/CURRENT_STATUS.md、DECISIONS.md 和必要阶段交接；标记 D3 为下一任务。

现在开始 D0。先简要说明实际查到的工程结构和本轮修改边界，然后在安全前置满足后直接实施 D1、D2。不要把桌面交付改成网页预览，也不要等待我先完成下载插件。
```
